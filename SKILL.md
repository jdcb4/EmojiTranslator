# EmojiTranslator

Use this skill when working inside this repository.

## Instructions

1. Follow `AGENTS.md` first.
2. Read `docs/PROJECT_INDEX.md` before changing project structure, commands, or documentation.
3. Keep the app as a Vite, React, and strict TypeScript project unless a later documented decision supersedes that stack.
4. Use semantic design tokens from `src/styles/tokens.css` and `tailwind.config.ts` for visual styling.
5. Keep product behavior minimal until the user moves a requirement into active work.
6. Run `pnpm run verify` and `pnpm run format:check` before claiming implementation work is complete.
